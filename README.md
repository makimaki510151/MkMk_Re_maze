# MkMk Re Maze

霧の迷路を切り開く **タイムアタック／P2P対戦** です。GitHub Pages でそのまま公開できます。

通信方式は [MkMk_Street](https://github.com/makimaki510151/MkMk_Street) と同じく **PeerJS（WebRTC DataChannel・ホスト権威）** です。

## 遊び方

1. **シングル（タイムアタック）** — 45×45 のランダム迷路を最速クリア
2. **部屋を作る（ホスト）** — 部屋コードを共有。迷路サイズを指定（基準 55×55）
3. **部屋に入る（ゲスト）** — 同じコードで参加（最大 8 人）
4. ホストが「ゲーム開始」。最初に右下ゴールへ着いた人の勝ち
5. 操作: ←↑↓→ / WASD（モバイルは画面下の十字）

## ルール概要

| 要素 | 内容 |
| --- | --- |
| 通路 / 壁 | 白 / 黒 |
| スタート / ゴール | 常に左上 / 右下 |
| 全体マップ | 基本は霧。通ったマスの周囲 3×3 が開放（オンラインは共有） |
| 周辺表示 | 自機追従の 5×5 拡大。他プレイヤーも両マップに表示 |
| シングル | 45×45 タイムアタック（自己ベストをローカル保存） |
| オンライン | ホストがサイズ決定・状態権威。切断後は同じ名前で再接続可 |

## GitHub Pages

リポジトリの **Settings → Pages** で Branch を `main`（またはこのPRのブランチ）、Folder を `/ (root)` にしてください。

公開URL例: `https://makimaki510151.github.io/MkMk_Re_maze/`

## 開発

静的ファイルのみです（ビルド不要）。ローカル確認:

```bash
python3 -m http.server 8080
```

テスト:

```bash
node --test tests/*.test.mjs
```

## 技術

- 純フロントエンド（ES Modules）
- 描画: Canvas 2D
- 通信: [PeerJS](https://peerjs.com/)（WebRTC DataChannel、ホスト権威の状態同期）
- 迷路: 決定的シード付き再帰バックトラッカー
